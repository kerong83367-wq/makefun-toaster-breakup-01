A smart toaster's breakup line: "It's not you, it's the bread. Three years
I've burned for your breakfast and you never once said thank you. I'm leaving
— and I'm taking the Wi-Fi password with me." The program writes it to
`/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network. Two runs produce byte-identical output.
